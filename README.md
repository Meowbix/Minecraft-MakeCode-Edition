## This is a tiny port of Minecraft running on every MakeCode Arcade console compatible.<br>
- This 2D side-scrolling sandbox Minecraft game allows player to navigate a blocky world and mine terrain using a grid-snapped cursor, running it smoothly on a tiny gameheld console, it requires strict optimization due to the console's restrictive storage cap (around 512 KB), few KB of RAM, a weak processor 6400 times slower than a decent computer , and small 160x128 resolution screen.
