## This tiny build is a little Minecraft game running on a Meowbit.<br>
- While this 2D side-scrolling sandbox prototype allows players to navigate a blocky world and mine terrain using a grid-snapped cursor, running it smoothly on a Meowbit requires strict optimization due to the console's restrictive 512 KB storage cap, 96 KB of RAM, weak processor, and small 160x128 resolution screen.
